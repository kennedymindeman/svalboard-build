# svalboard-build

Build tracker for my Svalboard self-print kit. One **issue per assembly step**, in
order — the lowest-numbered open issue is the next thing to do. Close an issue when
the step is done.

All printing is complete; what remains is assembly. The authoritative instructions
are the Self-Print Build Guide PDF (in the private supporters repo, local copy at
`~/projects/svalboard-self-print/docs/` on the MacBook); issues cite its page numbers.

A weekly Claude routine reads the open issues here every Sunday morning and books a
build-hour calendar block with the next step.
